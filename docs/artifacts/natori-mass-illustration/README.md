# 量産イラストの依頼フォーム改善

2026-09-08。今回の変更はローカルのみ。本番へは未デプロイ。

## 変更箇所

- `PortfolioHero.tsx`: 冒頭の価格表示・料金カードを削除。納期・返信目安は短い文章で表示。
- `PortfolioStructuredCommissionForm.tsx`: 相談時は内容欄を先に、見積もり時は依頼の種類などを先に表示。量産イラストは「おばけ／魔女」、必須の表情指定、専用の追加オプションを表示。用途・条件、予算・納期、キャラクター詳細は自動で開かない。
- `massProductionIllustration.ts`: 衣装カラーチェンジ500円、表情差分500円、商用利用1,000円を定義。
- `portfolioRequestForm.ts`: 選択内容を既存の依頼データ形式で送信。通常依頼と量産依頼のオプションが混ざらないよう切り替え。
- `requestSchema.ts`: 新規量産依頼のデザイン・表情指定をサーバー側でも検証。保存済みの旧形式データは引き続き読み取り可能。
- `pricingSuggestion.ts`: 量産専用の追加料金を見積もり候補へ反映。基本料金は既存の確認フローを維持。

正確な置換ブロック・行位置は `changes.patch` に記録。DB変更は不要。

## 検証

- 関連6ファイル・141テスト成功（フォーム、Hero、送信データ、入力検証、見積もり候補、受付API）。メール・DBはテスト用モック。
- TypeScript: `tsc --noEmit --incremental false` 成功。
- Playwright: 390px / 1440pxでDOM順序、入力保持、必須チェック、デモ送信、折りたたみ状態、横スクロールなしを確認。ページ例外・コンソールエラーなし。記録された中断通信はGoogle Analyticsへのリクエストのみ。
- スクリーンショットはローカルのエトリエデモ（サンプルデータ）で撮影。公開サイトそのものの画像ではありません。

## 手動確認手順

1. ポートフォリオのHeroで価格カードがなくなったことを確認。
2. 名前・メール・相談内容を入力し、「見積もりを希望」へ切り替える。種類のセクションが先に移り、入力内容が残ることを確認。
3. 「量産イラスト」を選び、デザインで「おばけ」「魔女」を選べることを確認。表情指定を空のまま送信すると必須チェックされることを確認。
4. 衣装カラーチェンジ・表情差分・商用利用の表示金額を確認。用途・条件、予算・納期、キャラクター詳細は閉じたままであることを確認。
5. デモでは表情指定を入力して送信完了まで確認可能。本番の実メール送信は今回実施していません。
